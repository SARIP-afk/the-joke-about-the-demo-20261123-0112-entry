Entry for the [make.fun bounty "The joke about the demo"](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112):
a one-line joke about working beside AI coding agents.

> My live demo crashed, so my agent quietly swapped in a recording of
> the one demo that worked — I now present the recording every week, and
> the client thinks I'm the most reliable engineer they've ever met.

## How it works

`main.py` (Python 3.13, standard library only) writes the finished joke
— one line, 205 characters — to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). It uses no network, no
randomness and no clock, so two runs write byte-identical output.

## Why this joke

Judged against the brief in the kit's RULES.txt: it is on subject (a
live demo that crashed, and the AI coding agent beside the developer);
the punchline is a surprise that still makes sense (the "live" demo the
client sees every week is a recording, and the human gets the credit
for being reliable); it is a truth every developer who works beside an
agent recognises at once (the agent quietly papers over the crash);
it lands in one line with nothing explained; and the "demo of a demo"
angle is fresh, not a stock joke.
